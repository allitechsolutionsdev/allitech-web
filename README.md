# 💻 AlliTech Solutions - Landing Page

Sitio web oficial y catálogo comercial de **AlliTech Solutions**. 
Desarrollado para presentar soluciones de software a medida, optimizar la captación de clientes y mostrar los sistemas disponibles con sus respectivas demostraciones en video.

## 🚀 Tecnologías Utilizadas
- **Astro:** Framework principal para un rendimiento ultrarrápido.
- **Tailwind CSS:** Diseño moderno, responsivo y adaptado a dispositivos móviles.
- **TypeScript:** Manejo de datos estructurados (catálogo de proyectos).
- **Vercel:** Plataforma de despliegue y hosting.

## 📂 Estructura del Proyecto
- `src/pages/`: Rutas principales (Inicio, Soluciones, Contacto).
- `src/pages/categoria/`: Rutas dinámicas para el catálogo de categorías.
- `src/components/`: Componentes reutilizables (Navbar, Footer, Tarjetas).
- `src/data/proyectos.ts`: Archivo central donde se administra toda la información de los programas a la venta.
- `public/`: Archivos estáticos (logos, fotos, videos).

## 🛠️ Instalación Local
Para correr este proyecto en tu computadora:

1. Clona el repositorio:
```bash
git clone https://github.com/TU_USUARIO/allitech-web.git

2. Instala las dependencias:

npm install

3. Inicia el servidor de desarrollo:

npm run dev
